Before your first transfer

A few useful
things to know.

Read the documentation ↗
Are transfers encrypted?

No. TransferCove has no encryption or authentication. Files travel over plain HTTP. Use it only inside a trusted, verified local network.

Do not expose the receiver to the public internet, configure port forwarding for it, or use it on public or untrusted Wi-Fi. Other devices that can reach the receiver do not need to sign in.

Does the sending device need an app?

No. Run TransferCove on the receiving computer, then open its local address in a modern browser on the sending device. A phone, tablet, or another computer can send files.

Where do my files go?

Files are saved in the receiving computer’s storage folder, which you choose in Settings → Storage. TransferCove does not use cloud storage for the transfer.

Why can’t my phone connect?

Connect both devices to the same trusted local network. In Settings → Connection, choose Use current LAN address, save, and start the server. Use the dashboard’s shareable address or QR code.

127.0.0.1 only works on the receiver itself; 0.0.0.0 is not an address to open in a browser. Your private-network firewall must allow the selected port. Some guest networks also block connections between devices.

How do I install or run TransferCove?

Visit GitHub Releases for the published builds and installation notes. To run from source, you need Python 3.14+ and Poetry. Follow the repository’s quick-start guide.

Is it free to use?

Yes. TransferCove is open source under the MIT license. There is no subscription or cloud account to create. You can inspect the code, report an issue, or contribute on GitHub.
